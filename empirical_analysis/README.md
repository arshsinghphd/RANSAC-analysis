## About This Notebook

This notebook contains the empirical analysis for the final project on **RANSAC (Random Sample Consensus)**, a robust model fitting algorithm introduced by Fischler and Bolles (1981).

In these experiments, I use synthetic two-dimensional Cartesian points rather than real image data. This abstraction eliminates image I/O complexity. I am able to geenrate data by assigning the parameters of a generating model, thus model recovery error can be measured precisely.

Each experiment is repeated `N_REPEATS = ` times with different random seeds. Mean model error and standard deviation are reported. Because RANSAC is a randomized algorithm with designed failure probability $p = 0.01$, occasional test failures are expected and not indicative of a defect.

## How to Run

### Step 1 — Compile and Run `experiments.c`

From the project root using Makefile command `run`:

```bash
cd empirical_analysis
make run
```

This compiles `experiments.c` against the C source files in `src/C/`,
runs the binary, and writes CSV data to `empirical_analysis/results/`.

### Step 2 — Open the notebook

```bash
# from empirical_analysis/
source .venv/bin/activate
jupyter notebook ransac_experiments.ipynb
```

While the notebook has all the graphs as a mark-up, if the graphs need to be refreshed, the notebook can be  run again.

Select kernel: **RANSAC Project**

Run all cells: **Kernel → Restart & Run All**

Plots are saved to `figures/`, relative to root of the project.

### Step 3 - Cleaning up 

One can clean up all the `*.out` files using Makefile command `clean`:

```bash
make clean
```
